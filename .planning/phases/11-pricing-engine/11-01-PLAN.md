  <action>
Create `convex/pricing.ts` with the following exports:

**Pure function (not a Convex function — plain TypeScript):**
```
computeCurrentPriceCents(launchDateMs: number, nowMs?: number): number
```
- Formula: `$2 * 2^(floor(weeksElapsed))`, capped at $64
- Guard: if `nowMs < launchDateMs`, return BASE_CENTS (200)
- `weeksElapsed = (nowMs - launchDateMs) / MS_PER_WEEK`
- `MS_PER_WEEK = 7 * 24 * 60 * 60 * 1000`

**Queries (public, authenticated):**

1. `getCurrentPrice` — No args. Reads pricingConfig, computes current price via `computeCurrentPriceCents`. Returns `{ configured: false, priceCents: null }` if no config row, or `{ configured: true, priceCents, priceUsd }`.

2. `getPricingConfig` — No args. Returns the config row or null. No auth required (public info).

3. `getFreeTierStatus` — No args, requires auth. Reads pricingConfig + userFreeTier for current user. Returns `{ exploreRemaining, evaluateRemaining, exploreFreeLimit, evaluateFreeLimit }` or null if not configured/not authenticated.

**Mutations:**

4. `setPricingConfig` — `internalMutation`. Args: `launchDate: v.number()`, `freeExploreLimit: v.optional(v.number())`, `freeEvaluateLimit: v.optional(v.number())`. Upsert pattern: if existing row, patch; else insert with defaults (freeExploreLimit: 1, freeEvaluateLimit: 1).

5. `createPayment` — `internalMutation`. Args: `userId: v.string()`, `sessionId: v.id("sessions")`, `amountCents: v.number()`, `stripeSessionId: v.optional(v.string())`. Inserts payment record with status "pending".

6. `updatePaymentStatus` — `internalMutation`. Args: `paymentId: v.id("payments")`, `status`, `stripePaymentIntentId: v.optional(v.string())`. Patches the payment record.

Follow established patterns from `convex/billing.ts`: import `getAuthUserId` from `./auth`, use `v` validators, use `.withIndex()` for queries.
