  <action>
Extend `convex/schema.ts`:
- Add `ideaKeywords` field to sessions table: `v.optional(v.array(v.object({ word: v.string(), area: v.number(), relevance: v.number() })))`
- Add `ideaSentence` field: `v.optional(v.string())` (the crystallized idea)
- Add `supportingSentences` field: `v.optional(v.array(v.object({ text: v.string(), areaIndex: v.number() })))`

Create `convex/ideas.ts`:
1. Query `getIdeaCard`:
   - Args: `{ sessionId: v.id("sessions") }`
   - Returns: `{ phase, ideaSentence, supportingSentences, ideaKeywords, ideaCardScore }`
   - Reads from session document

2. Internal mutation `updateIdeaKeywords`:
   - Args: `{ sessionId, keywords: { word, area, relevance }[] }`
   - Updates session.ideaKeywords

3. Internal mutation `setIdeaSentence`:
   - Args: `{ sessionId, ideaSentence, supportingSentences }`
   - Updates session.ideaSentence and session.supportingSentences
   - This is called when Claude extracts a coherent idea (triggers merge animation)

4. Action `extractIdeaContent`:
   - Args: `{ sessionId }`
   - Reads recent messages from session
   - Calls Claude to extract:
     - Keywords per area (6-14 words per area, with relevance scores)
     - If phase >= 3 and conversation has enough depth: extract ideaSentence + supportingSentences
   - Uses structured output format similar to phase assessment
   - Calls updateIdeaKeywords and/or setIdeaSentence mutations

Claude prompt for extraction should:
- Identify which of 6 exploration areas each message relates to
- Extract 2-3 word keywords/phrases that capture key insights
- Rank keywords by how central they are to the user's emerging idea
- When idea is crystallizing: extract one clear sentence that captures the core idea
- Extract 3-4 supporting sentences from conversation that connect to the idea
  </action>

  - Font size from layout
  - `<motion.text>` with fade-in animation (duration 2s)

- Uses useLayoutEffect to measure before paint
- Returns optimal fontSize

Create `src/components/idea-card/IdeaCardContent.tsx`:

- Only renders when isVisible (phase >= 3 and ideaSentence exists)
- Uses useFitText for idea sentence sizing
- Layout:
  - Idea sentence: bold, larger (from useFitText), dark gray, top position

- `<AnimatePresence>` wrapper for mount/unmount
- `<motion.div>` with fade-in (opacity 0->1, delay 1s after merge starts, duration 2s)
