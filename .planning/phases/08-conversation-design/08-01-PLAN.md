Create `src/lib/schemas/` directory with three schema files. These use Zod for Claude structured outputs via `zodOutputFormat`.

1. `src/lib/schemas/coverageExtraction.ts`:
   - Import `z` from "zod" and `getPhaseConfig, getTopicKeys` from "../phaseConfig"
   - Create `createCoverageSchema(phaseNumber: number)` that dynamically builds a Zod schema based on the phase's coverageTopics:
     ```typescript
     const depthEnum = z.enum(["not_mentioned", "surface", "moderate", "deep"]);

     export function createCoverageSchema(phaseNumber: number) {
       const topicKeys = getTopicKeys(phaseNumber);
       const topicsShape: Record<string, z.ZodEnum<["not_mentioned", "surface", "moderate", "deep"]>> = {};
       for (const key of topicKeys) {
         topicsShape[key] = depthEnum;
       }

       return z.object({
         topicsDiscussed: z.object(topicsShape),
         energyPeaks: z.array(z.string()).describe("Specific topics/moments with high user energy"),
         currentFocus: z.string().describe("Topic user is most engaged with right now"),
         depthSummary: z.object({
           topicsAtDeep: z.number(),
           topicsAtModerate: z.number(),
           topicsAtSurface: z.number(),
           topicsNotMentioned: z.number(),
         }),
         readyForPhaseCompletion: z.boolean(),
         whatsMissing: z.array(z.string()).optional().describe("Topics needing more depth if not ready"),
       });
     }
     ```
   - Export type `CoverageResult = z.infer<ReturnType<typeof createCoverageSchema>>`
   - Export `buildCoverageExtractionPrompt(phaseNumber: number, currentCoverage: Record<string, string>): string` that builds the system prompt for coverage extraction, including depth definitions:
     - SURFACE: Topic mentioned, no specific detail
     - MODERATE: Specific examples provided, some personal detail
     - DEEP: Multiple examples, emotional language, patterns identified by user

2. `src/lib/schemas/researchTriggers.ts`:
   - Define `TriggerDetectionSchema`:
     ```typescript
     export const TriggerDetectionSchema = z.object({
       triggers: z.array(z.object({
         category: z.enum(["market_claim", "competitor_mention", "pain_point", "assumption"]),
         quote: z.string().describe("Exact text from user that triggered detection"),
         suggestedSources: z.array(z.enum(["reddit", "hn", "producthunt", "tavily", "stackoverflow"])).max(3),
         researchAngle: z.string().describe("Specific search query or question to investigate"),
         priority: z.enum(["high", "medium", "low"]),
       })),
       shouldSuggest: z.boolean().describe("Based on intensity setting and trigger quality, should Claude suggest research now?"),
     });
     ```
   - Export `type ResearchTrigger = z.infer<typeof TriggerDetectionSchema>["triggers"][number]`
   - Export `buildTriggerDetectionPrompt(intensitySetting: "low" | "medium" | "high", searchedSources: string[]): string` with intensity guidance per CONTEXT.md:
     - low: Only explicit claims with no supporting evidence
     - medium: Claims + competitor mentions + clear pain point descriptions
     - high: Everything including implicit assumptions

3. `src/lib/schemas/scoreUpdates.ts`:
   - Define `RescoringSchema`:
     ```typescript
     export const RescoringSchema = z.object({
       opportunityName: z.string(),
       dimensionScores: z.object({
         market_fit: z.number().min(1).max(10),
         pain_urgency: z.number().min(1).max(10),
         timing: z.number().min(1).max(10),
         distribution: z.number().min(1).max(10),
         founder_fit: z.number().min(1).max(10),
       }),
       changes: z.array(z.object({
         dimension: z.string(),
         oldScore: z.number(),
         newScore: z.number(),
         direction: z.enum(["up", "down", "unchanged"]),
         explanation: z.string().describe("Natural language: why this changed"),
       })),
       overallAssessment: z.string().describe("1-2 sentence summary"),
       confidenceLevel: z.enum(["low", "medium", "high"]).describe("Based on evidence quality"),
     });
     ```
   - Export `type RescoreResult = z.infer<typeof RescoringSchema>`
   - Export `buildRescoringPrompt(): string` with the critical rules: scores CAN go down, be honest not encouraging, explain EVERY change, include confidence level.

All schemas use standard Zod (already in project via convex dependencies). Verify zod is available: `import { z } from "zod"`. If zod is not a direct dependency, note it needs installation but the convex ecosystem includes it.
