<task type="auto">
  <name>Task 2: Create Stripe HTTP actions and wire routes</name>
  <files>convex/stripe.ts, convex/stripeHelpers.ts, convex/http.ts</files>
  <action>
1. Create `convex/stripe.ts` with `"use node"` pragma at top. This file contains ONLY httpAction handlers (no queries/mutations — Convex "use node" restriction).

   a) `createCheckoutSession` httpAction:
      - Extract auth identity via `ctx.auth.getUserIdentity()` — return 401 if null
      - Parse JSON body: `{ path, name, description, amountCents }` — validate all present, return 400 if missing
      - Get userId from `identity.subject`
      - Create Stripe instance: `new Stripe(process.env.STRIPE_SECRET_KEY!)` (no explicit apiVersion — let it default)
      - Call `stripe.checkout.sessions.create()` with:
        - `mode: "payment"`
        - `line_items: [{ price_data: { currency: "usd", unit_amount: amountCents, product_data: { name: "Gap Finder — " + (path === "exploration" ? "Explore" : "Evaluate") + " Session" } }, quantity: 1 }]`
        - `metadata: { userId, path, name: name.substring(0, 40), description: (description || "").substring(0, 500) }`
        - `success_url: process.env.APP_URL + "?payment=success"`
        - `cancel_url: process.env.APP_URL + "?payment=cancelled"`
      - Return JSON response `{ url: session.url }` with status 200
      - Add CORS headers to response: `Access-Control-Allow-Origin: process.env.APP_URL`, `Content-Type: application/json`

   b) `stripeWebhook` httpAction:
      - Get `stripe-signature` header — return 400 if missing
      - Get raw body via `await request.text()` (NEVER request.json() — breaks signature verification)
      - Call `stripe.webhooks.constructEvent(payload, signature, process.env.STRIPE_WEBHOOK_SECRET!)` in try/catch — return 400 on failure
      - If `event.type === "checkout.session.completed"`:
        - Extract session object, metadata, payment_intent
        - Call `await ctx.runAction(internal.stripeHelpers.fulfillCheckout, { stripeSessionId: session.id, metadata: { userId: session.metadata!.userId, path: session.metadata!.path, name: session.metadata!.name, description: session.metadata!.description }, paymentIntentId: (session.payment_intent as string) || "", amountCents: session.amount_total || 0 })`
      - Return 200 for all events (Stripe expects 200 even for unhandled event types)

2. Create `convex/stripeHelpers.ts` (NO "use node" pragma — this runs in Convex default runtime so it can call mutations):

   a) `fulfillCheckout` internalAction:
      - Args: `stripeSessionId: v.string()`, `metadata: v.object({ userId: v.string(), path: v.string(), name: v.string(), description: v.string() })`, `paymentIntentId: v.string()`, `amountCents: v.number()`
      - Calls `ctx.runMutation(internal.sessions.createPaidSession, { userId: metadata.userId, name: metadata.name, path: metadata.path as "exploration" | "evaluation", description: metadata.description || undefined, amountCents, stripeSessionId, stripePaymentIntentId: paymentIntentId })`
      - The createPaidSession mutation handles idempotency internally (checks for existing payment with same stripeSessionId)

3. Update `convex/http.ts`:
   - Import `createCheckoutSession` and `stripeWebhook` from `"./stripe"`
   - Add route: `http.route({ path: "/api/stripe/create-checkout", method: "POST", handler: createCheckoutSession })`
   - Add CORS preflight route: `http.route({ path: "/api/stripe/create-checkout", method: "OPTIONS", handler: httpAction(async () => new Response(null, { headers: { "Access-Control-Allow-Origin": process.env.APP_URL!, "Access-Control-Allow-Methods": "POST", "Access-Control-Allow-Headers": "Content-Type, Authorization" } })) })`
   - Add route: `http.route({ path: "/api/stripe/webhook", method: "POST", handler: stripeWebhook })`

Note: `httpAction` can be imported directly from `convex/server` for inline handlers or from `./_generated/server`. For the CORS preflight inline handler in http.ts, import from `convex/server`.
