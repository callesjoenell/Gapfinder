Create `src/components/idea-card/utils/blobShapes.ts`:
- Export `BLOB_SEEDS: number[]` - 6 seed values for reproducible blob shapes
- Export `generateBlobPath(seed: number, centerX: number, centerY: number, radius: number, edges?: number): string`
  - Uses seed for deterministic randomness (same seed = same shape)
  - Generates irregular organic shapes using polar coordinates with noise
  - Default 8 edges for smooth-enough curves
  - Returns SVG path `d` attribute string
- Export `BLOB_COLORS: { fill: string; gradient: string }[]` - 6 color pairs between yellow (#FFD700) and orange (#FFA500)
- Export `BLOB_ZONES: { x: number; y: number; maxDrift: number }[]` - 6 zone definitions as STARTING positions (outer ring arrangement)
- Export `CARD_CENTER: { x: number; y: number }` - the center point blobs drift toward

Create `src/components/idea-card/hooks/useBlobAnimation.ts`:
- Export `useBlobAnimation(phase: number, shouldReduceMotion: boolean)`
- Returns `{ blobTransforms: { x: number; y: number; scale: number }[], edgeClarity: number }`
- Edge clarity: phase 0 start = 0.1 (1%), phase 0 end = 0.5 (50%), phases 1-2 = 0.6, phase 3+ = 0.8
- **CENTRIPETAL DRIFT (CARD-02 "drifting together"):**
  - Each blob has independent subtle drift within its local zone: x: [-10, 10], y: [-8, 12] pixels
  - PLUS gradual centripetal pull toward CARD_CENTER based on phase:
    - Phase 0: blobs at 100% of their starting zone distance from center
    - Phase 1: blobs at ~85% of distance from center
    - Phase 2: blobs at ~70% of distance from center
    - Phase 3+: merge animation takes over (handled in BlobBackground.tsx)
  - Use interpolation: `currentPos = lerp(zonePos, CARD_CENTER, convergenceFactor)`
  - convergenceFactor = clamp(phase * 0.15, 0, 0.3) for phases 0-2
- 60-second animation cycle per blob (glacial motion) for local drift
- If shouldReduceMotion, return static positions (no animation, but still apply convergence)
- Use Motion's useMotionValue and useTransform for GPU-accelerated values
